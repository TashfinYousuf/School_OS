## 2. Action Item Details & Resolution Paths

### BLK-01: SMS Gateway Provisioning
- **Current State:** The system uses transactional outbox queuing (`notification_outbox`) with exponential retry backoff. When run without SMS credentials, outgoing messages queue in `PENDING` or route to `mock` delivery without crashing.
- **Resolution:** Once the school owner acquires GreenWeb or Osel SMS credits, enter the token in `backend/.env`. Zero code changes required.

### BLK-02: Automated Payment Rails
- **Current State:** School fee collection and student admission receipts operate flawlessly with cash counter, bank transfer, and manual bKash transaction reference recording (`admission_receipts` table).
- **Resolution:** Optional activation of automated direct API payment gateway when merchant contracts are executed.

### BLK-03: Production Hostname & TLS
- **Current State:** Nginx reverse proxy configuration is ready in `nginx/nginx.conf` and `docker-compose.prod.yml`.
- **Resolution:** Once public IP address is assigned by hosting provider, update DNS records and start Nginx container.
