## 2. Adversarial Test Results & Enforcement Verification

Ten adversarial bypass vectors were executed to verify that unentitled tenants cannot exploit commercial tier boundaries:

| Attack Vector | Simulated Scenario | Expected Response | Observed Response | Status |
| :--- | :--- | :--- | :--- | :--- |
| **Direct API Invocation** | `free_trial` tenant calling `POST /api/v1/campus/branches` (multi-branch) | HTTP 403 Forbidden | HTTP 403 `FEATURE_NOT_ENTITLED` | PASSED |
| **AI Quota Exhaustion** | Tenant attempts generating 50 questions with 30 monthly quota remaining | Blocked before API call | HTTP 403 Quota Exceeded | PASSED |
| **Student Capacity Overflow** | Tenant on 100-student cap admits 101st student | Blocked at admission | HTTP 403 Limit Reached | PASSED |
| **Suspended Tenant Mutation** | Suspended tenant attempts creating an exam schedule | Blocked write action | HTTP 403 `SUBSCRIPTION_SUSPENDED` | PASSED |
| **Suspended Tenant Read Access** | Suspended tenant requests student roster and report cards | Permitted (non-destructive) | HTTP 200 OK | PASSED |
| **Forged Tenant ID** | Attacker injects another school's `tenant_id` in request header | Blocked by token validation | HTTP 403 Forbidden | PASSED |
| **Cross-Tenant Data Exposure** | Querying students belonging to another tenant | 0 rows returned (RLS) | 0 rows returned | PASSED |
| **Plan Tampering via Profile** | Tenant attempts modifying `plan_tier` in institution profile | Field ignored or rejected | Unchanged in database | PASSED |
| **Pilot Code Verification** | Tenant provides valid `KIDSSHINE` pilot code | Activated at 0 BDT | Activated with full pilot entitlement | PASSED |
| **Invalid Pilot Code** | Tenant provides fake code `KIDS_FREE_999` | Standard pricing applied | Standard quote returned | PASSED |

## 3. Findings & Residual Risks

1. **Deterministic Pre-flight Reservation:** The application reserves quota (`with_for_update`) prior to external LLM invocation, preventing financial loss from failed downstream network timeouts.
2. **Residual Risk:** In offline PWA mode, teachers can record roll calls locally without active internet. If a tenant is suspended while devices remain offline, the offline actions flush once connection resumes. This is intentional and compliant with educational continuity policies.
