# ROLE-BASED LOGIN AND ONBOARDING GUIDE
## Institutional Operator Manual: Step-by-Step Access Procedures

**Document ID:** EOS-UAT-007  
**Audience:** School Leadership, IT Coordinators, Teachers, Students, Guardians  
**Pilot Institution:** Kids Shine International School (KSIS)

---

## 1. Platform Super Admin

### Purpose
System-wide tenant administration, feature toggle management, institutional provisioning, and audit oversight.

### Access Procedure
1. Navigate to `/platform/login`.
2. Enter Super Admin credentials (e.g., `owner@educationos.internal`).
3. Enter current TOTP 6-digit code generated by Authenticator App.
4. Upon authentication, you will be directed to `/dashboard/platform`.

---

## 2. School Admin (Principal / Headmaster)

### Purpose
School setup, student/teacher record management, academic routines, fee configurations, and institutional reports.

### Access Procedure
1. Navigate to `/login`.
2. Select the **Staff / শিক্ষক ও কর্মচারী** tab.
3. Enter registered email (e.g., `admin@kidsshine.com`) and password.
4. Click **Sign In**.
5. Upon successful verification, you are routed directly to `/dashboard`.

---

## 3. Teacher

### Purpose
Daily attendance taking, marks entry, class routine viewing, student doubt resolution, and notice board posting.

### Access Procedure
1. Navigate to `/login`.
2. Select the **Staff / শিক্ষক ও কর্মচারী** tab.
3. Enter teacher email (e.g., `kaynat@kidsshine.com`) and password.
4. Click **Sign In**.
5. System routes teacher to `/dashboard` with teacher-scoped permissions (attendance, exams, notices).

---

## 4. Student

### Purpose
Accessing syllabus, taking live online exams, asking questions to AI Doubt Solver, viewing attendance and fee receipts.

### Access Procedure
1. Navigate to `/login`.
2. Select the **Student / শিক্ষার্থী** tab.
3. Enter the institutional Student ID (e.g., `KSIS-2027-001`).
4. Enter password / access PIN.
5. Click **Sign In**.
6. System routes student to `/dashboard/learning` or `/dashboard/doubt-solver`.

---

## 5. Guardian (Parent)

### Purpose
Monitoring child's daily presence/absence, reviewing report cards, receiving school notices, and paying tuition fees.

### Access Procedure
1. For newly admitted students, the guardian receives an onboarding invitation via SMS/Email containing an activation link:  
   `https://schoolos.app/activate?token=<activation_token>`.
2. The guardian opens the link and sets a personal password.
3. Once activated, navigate to `/login` and select the **Guardian / অভিভাবক** tab.
4. Enter registered phone number (e.g., `01673998729`) or email and the password.
5. Click **Sign In**.
6. System routes guardian to `/dashboard/guardians` displaying linked children.
